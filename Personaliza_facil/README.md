# Personalizados (TypeScript)
Vue 3 + TS + Router + Pinia + Vite. Sem backend (localStorage).

    npm install
    npm run dev
    npm run typecheck

Login: selecione "Entrar" para abrir o modal e acesse com nome de usuário e senha.
Administrador: usuário admin, senha admin123 (demonstração).
Cadastros e senhas ficam no localStorage deste navegador; autenticação real exige um servidor.
Regras de capacidade: src/config/negocio.ts
